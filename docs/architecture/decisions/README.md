# Architecture Decision Records

Create one ADR per significant decision. Suggested filename format: `ADR-002-session-strategy.md` (`ADR-NNN-title.md`).

## ADR template

# ADR-NNNN: Decision title

- Status: Proposed | Accepted | Superseded
- Date:
- Decision owners:

## Context
What problem or constraint requires a decision?

## Decision
What is being chosen?

## Alternatives considered
List plausible alternatives.

## Consequences
Include benefits, costs, security implications, operational implications, and migration impact.

## Verification
How will the decision be validated?
